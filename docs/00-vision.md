# 00. Видение

## Проблема

Агентам и новым разработчикам трудно понять, как устроен сервис: какие в нём фичи, что запускает каждую, через какие компоненты проходит и куда пишет. Автогенерируемая «память» по сессиям (вроде claude-mem) отвечает на вопрос «что мы делали», но не на вопрос «как это работает». Свалка markdown без ревью быстро устаревает и теряет доверие.

## Цель

Единый **хаб знаний о сервисе**, который:

- раскладывает сервис на фичи и описывает каждый процесс **от триггера до стока** (БД, очередь, внешний сервис);
- рисует понятные диаграммы, читаемые и нетехническим человеком;
- содержит только то, что **прошло ревью** (или явно помечено как непроверенное);
- отдаётся любому harness/агенту по **MCP**;
- расширяем по всем осям (язык, источники, LLM, хранилище, индекс, рендер, правила ревью).

## Принципы

1. **Модель, а не тексты.** Структурная модель — источник правды; документы и диаграммы — её представления.
2. **Evidence для каждого утверждения.** `файл:строки@коммит`. Нет доказательства — это гипотеза, и она первой идёт на ревью.
3. **Детерминированное сначала.** Статический анализ даёт проверяемую базу; LLM только именует, группирует, объясняет.
4. **Человек в контуре, но без ритуала.** Объём ревью мал и ранжирован по риску; кликнуть «да» не читая нельзя.
5. **Абстракции сразу.** Каждый аспект — за портом (Strategy + реестр), как `SourceCollector` в worklog-tracker.
6. **Только чтение.** Хаб не меняет анализируемые репозитории.
7. **Локально по умолчанию.** Старт на локальной папке; хранилище, LLM и индекс заменяемы.

## Не цели (пока)

- Интеграции с CI/GitLab, вебхуки, автообновление по мержам.
- Многосервисная карта и межсервисные связи (модель их допускает, реализация позже).
- Генерация кода или изменение сервиса по знаниям.
- Полноценный векторный поиск (достаточно FTS; вектор — адаптер позже).

## Для кого

- **Разработчики сервиса:** ревьюят и дополняют знания.
- **Агенты (через MCP):** быстро находят нужную фичу, поток, зависимости.
- **Нетехнические читатели** (аналитики, менеджеры): читают бизнес-описания и верхнеуровневые диаграммы.
